Orchestrated Robotic Build & Integration Toolkit

AI-powered autonomous software development with self-improvement, smart model selection, and best practices enforcement.

Get Started View on GitHub

Quick Start

📦 Install via npm

npm install -g @davrock/orbit

🔧 From Source (Unix/macOS)

git clone https://github.com/davrock/orbit.git && cd orbit && ./install.sh

🚀 First Flight

$ orbit launch "add user authentication"
🚀 Mission: launch | Task: add user authentication
📋 Phase: plan (mission-planner, ⚡ standard)
✓ Planning complete
⚙️ Phase: implement (pilot, ⚡ standard)
✓ Implementation complete
🧪 Phase: test (specialist, ⚡ standard)
✓ Tests passing
✅ Mission complete!

Key Features

🚀

Multi-Phase Missions

Orchestrate complex development workflows with predefined mission templates for features, bugs, security, and more.

🧠

Smart Model Selection

Auto-select optimal LLM tier per task. Premium for security, standard for dev, fast for docs. Save tokens intelligently.

🔄

Self-Improvement Loop

Autonomous evolution system that processes task queues, GitHub issues, and self-identifies improvements.

🎯

Zero Configuration

Auto-detects project type, tech stack, test commands, and tools from your existing project files.

📚

Best Practices Built-in

All agents reference coding standards, testing patterns, security guidelines, and documentation conventions.

⚡

Parallel Execution

Ultrawork, Swarm, and Pipeline modes for intelligent parallel and sequential task distribution.

Mission Types

🚀 Launch Mission

plan → implement → test → review → commit

Full feature development workflow with comprehensive planning, implementation, testing, and review phases.

orbit launch "add user authentication"
  • ✓ Complete feature development
  • ✓ Automated testing and review
  • ✓ Best practices enforcement

🔧 Repair Mission

debug → implement → test → commit

Bug fix workflow with debugging phase, implementation, testing, and commit.

orbit repair "fix login crash on mobile"
  • ✓ Root cause analysis
  • ✓ Regression test creation
  • ✓ Cheaper models for cost savings

⚡ Warp Mission

implement → commit

Quick changes and simple updates. Minimal overhead for fast iterations.

orbit warp "rename userId to userID"
  • ✓ Fastest execution
  • ✓ Simple refactoring
  • ✓ Documentation updates

🛡️ Shields-Up Mission

plan → implement → security → test → review → commit

Security-focused workflow with dedicated security review phase using premium models.

orbit shields-up "add payment processing"
  • ✓ OWASP Top 10 checks
  • ✓ Vulnerability scanning
  • ✓ Security-officer review

🔄 Ralph Mission (Persistent)

implement → test → review → commit (with auto-retry)

Never-give-up mode with automatic retries, model escalation, and crew rotation.

orbit ralph "implement complex feature"
  • ✓ Up to 10 retry attempts
  • ✓ Auto model escalation
  • ✓ Crew rotation for fresh perspective

🐝 Swarm Mission (Parallel)

plan → parallel execution → review → commit

Intelligent parallel execution with dependency awareness and coordinated task distribution.

orbit swarm "implement user authentication system"
  • ✓ Dependency graph analysis
  • ✓ Wave-based parallel execution
  • ✓ Context sharing between tasks
